# Vitae — Automated CV Pipeline

This repository contains the source code for my CV, written in LaTeX and automatically built and deployed using GitHub Actions.

Instead of maintaining static resume files, this setup treats the CV as a version-controlled, reproducible artifact.

## Project Structure

```text
.
├── cv.tex          # Primary LaTeX source
├── .github/workflows # CI pipeline configuration
├── cv.pdf           # Generated PDF (if stored)
└── README.md
```
